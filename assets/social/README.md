# PingLet social banners

- `pinglet-x-header-1500x500.png`: X profile header.
- `pinglet-facebook-cover-1640x624.png`: Facebook Page cover.
- `pinglet-social-profile-1024.png`: high-resolution universal profile image.
- `pinglet-x-profile-400.png`: X profile image.
- `pinglet-facebook-profile-320.png`: Facebook Page profile image.
- `source/`: editable SVG compositions.

Both designs reserve the left side for platform profile-photo overlays and keep essential branding within the center-right safe area.

Rebuild from the repository root:

```bash
./assets/social/generate-banners.sh
```
